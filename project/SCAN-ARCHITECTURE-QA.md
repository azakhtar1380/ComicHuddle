## PostgreSQL integrity and authorization

The actual SQL suite establishes nonnull UUID references, exact copy-owner/listing relationships, distinct duplicate physical copies, provisional rows with matching review receipts, custom quarantine, mixed-lot custom aggregation and one active claim per physical copy. A lot is valued per copy: incomplete coverage exposes a priced subtotal and Unknown whole-lot rating. No missing quote becomes zero.

Exact Raw/graded condition, grade, company, label, premium key and currency matching is exercised. Missing, stale, future, revoked-rights, unverified and insufficient-sample observations cannot price a listing. Administrative estimates remain separate. Threshold tests check the exact cent boundaries, signed variance, very-low-price caution and immutable provenance. Public responses omit restricted proof URLs, internal methodology, license references, purchase cost and private notes.

Moderation tests execute real transactional functions: active administrator checks, spoofed actor rejection, version conflicts, canonical aliases, distinct-copy/lot remapping, unchanged unrelated target-listing versions, exact idempotent retry and changed-payload conflict. An injected failure at the late durable audit write rolls back the entire merge. Sold/order/bid tests preserve settled snapshots, release reservations, mark copies sold, reject old-owner relisting and enforce allocations/duplicate-order/bid anchors.

Restricted nonowner roles are essential to the result. Tests verify that collectors cannot mark their own metadata VERIFIED, approve sources or read peers' copies/submissions. Ingestion can write a reviewed baseline but cannot approve source policy or spoof its recorder. Moderator capability alone cannot replace active admin membership. The public HTTP projection, trusted origin, JSON type, actual UTF-8 byte cap, dishonest Content-Length, context reset and generic error responses are exercised against the real engine. The actual SQL collection adapter preserves DECLARED metadata and UNKNOWN premium comparison, stores private Raw/slab ownership, resolves aliases, replays the same payload and rejects changed-payload/cross-account reuse.

The local reference API → PostgreSQL → public DTO → actual card mode/callback bridge also passes. Its DTO-to-directory-card mapping is an explicit test adapter; this is not a claim that the production PostgreSQL directory endpoint is deployed.

## Defects and verification boundaries

Independent role testing reproduced the approval `42702` ambiguous-column error and ingestion/buyer-bid `42501`/`P0002` capability failures. Qualified SQL references and narrow protected trigger reads repaired them; regressions pass. Privilege review additionally led to protected verification columns, source approval/reviewer checks and recorder ownership tests. No failure remains in the final automated scope.

PGlite executes real PostgreSQL constraints, PL/pgSQL, transactions, roles and RLS, but has one backend. Superuser seeding is separated from restricted-role tests. It cannot establish independently concurrent server transactions, pooler behavior, TLS/server authentication, replica consistency or recovery operations. Its [official documentation](https://pglite.dev/docs/) describes the single-connection design.

Scratch-only native PostgreSQL 18.4 binaries could report their version, but a server was not started: the workspace maps only UID/GID 0, and PostgreSQL requires a non-root process identity. Nonroot ownership and supported namespace creation were unavailable. No UID check was bypassed. [The prepared server runner](../architecture/postgres/tests/run-isolated.mjs) and [two separate-client race cases](../architecture/postgres/tests/concurrency.mjs) remain **unrun** for a suitable isolated CI host.

The [prepared Playwright suite](../architecture/e2e/README.md) contains four browser acceptance cases and is **unrun**. It requires an approved external staging browser/CI environment; its write case requires an explicitly enabled test-account session. No preview server, browser installation, improvised browser controller or hardware claim was used here.
