## What changed

Desktop menu: Home, Directory, Marketplace, Community, My Profile, Comic Workshop, Upcoming. Phone bottom navigation: Home, Directory, Marketplace, Community, Upcoming, Comic Workshop. My Profile also opens through the account drawer. No duplicate page-level primary menu is added on the mobile app.

FMV and GrailMatch are shown only as coming-soon products under Upcoming. Their old section URLs resolve before section validation, so saved links and account handoffs do not revive the active guides/swipe demo. Existing collection, want-list and future research/backend data are preserved. Marketplace unknown-value states do not invent current prices.

My Profile restores the current member’s own showcase even after another collector’s profile has been viewed on the same tab. Guests see an invitation to create a real free profile, without a fictional profile displayed as their own. Showcase sharing and grail-wall features remain available.

Community has been rebuilt: a combined feed from joined groups; paginated group discovery and My Groups; channels; newest/recently-active sorting and bounded search; discussion, question, shelf-showcase and latest-find posts; titles and owned photos; threaded replies and unique hearts; collector profile and messaging links; accessible create/post/discussion dialogs; report/delete controls. Editorial prompts are labeled and never counted as member content. Empty groups show honest invitations rather than invented activity.

Posts, replies and attached photos are for group members. Hidden showcase profiles may participate with their display name, as the composer discloses. Full collections, precise addresses and private contact/payment records do not become group content. Membership, moderation and two-way blocking govern reads/actions and media access. Account export/deletion removes or includes owned replies/reactions consistently.

Delayed requests and actions cannot overwrite a changed account, group, view or dismissed dialog. Native create/compose handoffs resume after session invalidation, and group creation tolerates its own legitimate autojoin refresh without accepting late unrelated completions. Photos have bounded dimensions and preserve private access.

## Directory source

Metron’s published commercial guidance permits CC BY-SA 4.0 metadata reuse, with attribution and ShareAlike for distributed adaptations. Its default multi-user API requires each app user’s own Metron account/token. Comic Vine’s public API is noncommercial, so no production import is configured.

Directory includes a per-member Metron connector alongside the 43-issue starter bibliography. Members paste a revocable token into a password field, explicitly search and select an issue. Token and lookup results are transient to that view. Fixed-origin authenticated proxy requests enforce same-origin authorization, current rules, deletion/restriction gates, byte/time/rate/pagination bounds and sanitized failures. A changed profile ID remounts the connector. Credentials never enter saved entries, persistent browser storage, exports or logs.

Adding a personal copy preserves the exact issue number, explicit provider ID/source URL and CC license separately from starter IDs. It has unrecorded condition and a private estimate of zero; that estimate is not FMV. Metron artwork, HTML synopsis, cover prices and ratings do not populate covers, valuations or CGC grades. Source/license attribution appears in the connector, saved provenance and footer. Field formatting is disclosed.

No real Metron account/token was available. No authenticated provider HTTP status or successful live lookup was observed. The connector is implemented and fixture-tested, not claimed connected. The full shared directory needs authorized catalog delivery or a written central-service arrangement. Cover images need an independent rights basis. METRON-SETUP.md gives the connection steps; METRON-DIRECTORY-DECISION.md includes a ready-to-send owner inquiry. Nobody has contacted the provider, created its account or committed money.
