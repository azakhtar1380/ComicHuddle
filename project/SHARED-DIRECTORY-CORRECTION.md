# Shared directory correction

9 October 2026. The founder requires a preloaded ComicHuddle catalog, with no customer-supplied provider credentials.

The prior release used a personal Metron connector and did not satisfy that experience. It has been removed from the customer-facing Directory. The existing 43-issue starter bibliography remains directly searchable and usable for account entries. Full Metron/Comic Vine coverage is not connected; no data was silently populated or invented.

Metron's commercial metadata license permits CC BY-SA 4.0 reuse. Its API-account policy describes individual accounts for multi-user apps and one business account for a business’s own store/stock. This does not establish that every reader of a lawfully delivered shared directory needs a Metron account. Confirm our central batch-sync arrangement with the provider, or obtain its authorized catalog snapshot and updates. No anonymous bulk delivery route has been verified.

Comic Vine’s public API is explicitly noncommercial. A separate commercial agreement is required for its API in this business. Neither source’s API key grants publisher cover rights or current FMV.

Owner Data Studio includes a reviewable email draft to bpepple@metron.cloud asking for central business-owned sync or catalog delivery, schema/sample, quotas and terms. The founder is willing to pay; no amount is committed, no account is created and no message is sent. Provider credentials and the approved dataset are not available in this session.

Intended integration: provider credentials only in server secrets; authorized batch import to ComicHuddle’s shared catalog; visitors search the indexed database; edition/source/license provenance and independently cleared covers retained. One visitor’s personal token is not silently pooled into this catalog. The retired personal adapter and its regression fixtures remain as historical engineering code, with no mounted customer credential form.

The new change is a customer-experience correction and owner acquisition path. It is not a complete catalog integration. FMV/GrailMatch stay in Upcoming; Community, My Profile, Workshop, marketplace and private payment boundaries remain unchanged.

Primary sources: https://metron-project.github.io/blog/commercial-api-use and https://comicvine.gamespot.com/api/
