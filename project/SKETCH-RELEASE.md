# ComicHuddle founder-sketch release

Prepared 13 October 2026. Existing owner-private audience preserved.

## Delivered scope

Home focuses on Directory, Marketplace, My Profile, Comic Workshop and a scanner. Desktop/mobile share six main destinations; mobile keeps a single bottom dock. Coming Soon contains FMV, Community and GrailMatch. Earlier Community links resolve to Upcoming; existing group data and server privacy safeguards are retained.

Directory: keyboard-accessible shared catalog dropdown; publisher-to-series browse tree; breadcrumbs; bounded issue cards; exact directory ID buy filter; add-owned-copy action; verified base-entry GoCollect research links with explicit manual fallback. All current record counts remain actual, with starter/import coverage disclosed. This is not a claim that a complete GCD or Metron catalog has been imported.

Marketplace: owned single-copy and collection listing flows, auctions retained as nonbinding previews, shipping/local pickup/both modes, city/state filters, truthful seller identity and no invented ratings. Negotiated trade proposals retain the exact offered and requested copies in a private agreement; sellers can accept or decline and requesters can cancel pending offers. Acceptance records the terms only: it does not transfer inventory or money, reserve a listing, or claim a completed/protected swap. Provider-linked edition snapshots are validated against the stored canonical issue, including concurrent changes. Pickup-only listings cannot enter current shipping checkout. Listing entry can open shared catalog/manual Add Comic and return to its draft without opening an overlapping collection drawer.

Profiles: city/state requested with public-city guidance, collections for both collectors and care providers, shareable collector showcase and private collection ownership.

Comic Workshop: city/state and studio/collector name search; local area rankings requiring genuine review counts; service menus and real provider prices; three-provider comparisons; messaging, quotes and existing private custody records. Paying never changes organic ratings.

Scanner: camera capture/upload and optional browser barcode/text assistance, local-photo privacy, manual exact-issue confirmation and camera/blob cleanup. No licensed visual cover index or server AI recognition service is connected. Browser capabilities vary; native Scan opens this website flow. A photo does not determine grade, authenticity or FMV.

See SKETCH-BUSINESS-MODEL.md for exact provider sources and unit economics. Commercial catalog metadata, cover display and recognition rights, and valuation feeds require separate verification.
